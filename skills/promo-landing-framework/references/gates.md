# Гейти

| Gate | Required evidence | Stop condition |
|---|---|---|
| G0 Scope Ready | Full/Fast/phase route, owners | product/host/deliverable unknown |
| G1 Brief Ready | one conversion, exact CTA route, integration boundary | several competing goals |
| G2 Truth & Legal Ready | Mechanics Model, Claims Matrix | P0 claim pending/prohibited |
| G3 Brand Ready | sources, Product KB snapshot, Brand Bridge | canonical identity/CTA/font unknown |
| G4 Story Ready | content map, storyboard, CTA map | section job or detail priority unclear |
| G5 Direction Selected | 3 visual options + scored selection | prose-only or reference-free direction |
| G6 Hero Approved | desktop/mobile/video/poster treatment | safe zone/crop/identity unresolved |
| G7 Design Approved | host context + content-only 1440/440/430/375 | mobile or final legal missing |
| G8 Asset Freeze | Asset Register, approved masters/delivery files | raw generation/style drift/missing alpha |
| G9 Feature Complete | local production build | placeholder art, wrong copy/routes/layout |
| G10 QA Green | legal, design, runtime, analytics evidence | errors/overflow/fidelity failure |
| G11 Released | explicit approval, terminal deployment, public verification | owner-only/unverified URL |
| G12 Learning Captured | retrospective and KB/skill updates | lessons exist only in chat |

Approval має називати версію артефакта й scope. Фраза з feedback не є погодженням.

Будь-яка зміна механіки чи claims повторно відкриває G2. Зміна identity/brand ownership відкриває G3. Layout або
responsive change after G7 reopens the affected design and asset/build QA.

# Контракт генерації — README Hero v7

## Ролі референсів

1. `SC-DERIVED-MASCOT-002` — ідентичність SlotCity;
2. `SC-DERIVED-POSE-004` — лише спокійна поза SlotCity з опорою;
3. `SC-CB-OWNER-ENSEMBLE-001` — ідентичність другорядних рудої героїні та синьої джинії;
4. `CB-DERIVED-MASCOT-003` — ідентичність Бета;
5. `CB-LIVE-POSE-005` — лише спокійна лежача поза Бета серед клубків.

## Зафіксована сцена

- SlotCity володіє світлим біло-жовтим містом розваг;
- CATBET володіє не міським котячим lore-світом: чорна/блакитна хутряна глибина, книга й клубки;
- головний маскот SlotCity спирається ліктем і схрещує щиколотки, не крокує в камеру;
- Бет спокійно лежить із лапами вперед, без стрибка, одягу чи людської анатомії;
- другорядні персонажі SlotCity менші й розташовані позаду;
- широкий центр вільний для великого 3D `VS`;
- немає згенерованих логотипів, слів, UI, соцмереж, claims або промосум.

У v7 точні SVG-логотипи та двоколірний `VS` були окремими об'ємними шарами композиції.

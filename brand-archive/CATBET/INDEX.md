# CATBET Brand Archive

**Design System version:** `0.9`

**Статус:** `OWNER-SUPPLIED BRAND BIBLE / TOKEN EXTRACTION PARTIAL` · **база:** CATBET Brand Bible,
Lore World, Product KB, production snapshots і reference register. Exact editable tokens/components
залишаються окремим extraction layer.

## Readiness

| Layer | Status | Blocker до canonical |
|---|---|---|
| Source provenance | `OWNER-SUPPLIED + LOCAL LIVE PACK` | two full brand boards, logo and mascot refs checksummed |
| Visual references | `STRONG 0.9 EVIDENCE` | exact editable masters/rights matrix still separate |
| Palette/tokens | `STRUCTURE READY / VALUES PENDING` | extract current variables/hex from supplied design system |
| Typography | `STRUCTURE READY / VALUES PENDING` | family/weights/modes/licensing |
| Components/CTA | `PARTIAL` | CATBET-native component inventory and properties pending |
| Mascot/characters | `OWNER-SUPPLIED / IDENTITY LOCKED` | no-clothes default, collar, character and visual rules extracted |
| Icon/3D families | `SEEDED` | masters, owners, current variant list and delivery specs |
| Art direction | `BRAND BIBLE EXTRACTED` | campaign-specific Brand approval remains required |
| Motion | `PARTIAL` | approved CATBET-native motion samples/tokens pending |
| Tone of Voice | `CORE EXTRACTED / LIBRARY PARTIAL` | dedicated CTA/error/legal phrase examples pending |
| Brand approval | `PENDING` | owner/date/exact 0.9 scope required |

Поля `PARTIAL/PENDING` не можна домислювати AI. Для нового лендінгу вони закриваються у G3 або
стають явно scoped exception з owner-ом.

## Update contract

Коли бренд-команда змінює Figma або assets:

1. записати old/new source і дату;
2. позначити affected family/token;
3. перевірити активні campaign repos;
4. оновити Product KB лише якщо змінилося правило прийняття рішень;
5. не перезаписувати історичний reference без change note.

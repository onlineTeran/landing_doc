# Контент-конфіг: тексти, переклади, кнопки

> Призначення: система керування всім копірайтом лендінгу — тексти живуть у JSON-файлах, які можна
> віддати копірайтеру без доступу до коду; мова перемикається `locale` продукту (контракт IframeBridge).
> **Спостережено** на референсному лендінгу (перша повна реалізація).

Мітки: **Спостережено** / **Виведено** / **Рекомендовано**.

---

## 1. Два файли контенту

| Файл | Хто редагує | Що всередині |
|---|---|---|
| `content/copy.json` | копірайтер | усі тексти лендінгу: блок → ключ → `{ ua, ru }` |
| `content/actions.json` | копірайтер + контент-менеджер | кнопки/CTA: id → `{ label: {ua, ru}, ga, action }` |

Правило «жодного тексту в компонентах»: grep кирилиці по `components/*.vue` темплейтах = 0 збігів
(крім коментарів). Аналогічно `https?://` — усі URL лише в `content/actions.json`.

## 2. Структура `copy.json` — проста, для копірайтера

```json
{
  "hero": {
    "tagline": { "ua": "…", "ru": "…" },
    "title_a": { "ua": "…", "ru": "…" },
    "title_b": { "ua": "…", "ru": "…" },
    "sub": { "ua": "…", "ru": "…" }
  },
  "faq": {
    "items": [ { "q": { "ua": "…", "ru": "…" }, "a": { "ua": "…", "ru": "…" } } ]
  }
}
```

Правила структури (**Спостережено**):
- **Блок = секція лендінгу** (hero/marquee/steps/map/faq/promos + common для наскрізного).
- Обидві мови поруч у кожному ключі — копірайтер бачить пару і не розсинхронізує переклади.
- Заголовки зі стилізованою частиною (`<span class="t-outline">`) розбиваються на `title_a`/`title_b` —
  розмітка лишається в компоненті, копірайтер не бачить HTML.
- a11y-тексти (aria-label, sr-only описи) — теж контент: ключі `aria_*`, `sr_*`.
- `_readme`-ключ на початку файлу — інструкція копірайтеру прямо в файлі.
- Копірайтер редагує ЛИШЕ значення `ua`/`ru`; ключі, структуру та кількість елементів масивів
  (steps.items = 3, faq.items = N) міняти не можна без розробника.

## 3. Структура `actions.json` — кнопки

```json
{
  "promo_open": {
    "label": { "ua": "Взяти бонус", "ru": "Забрать бонус" },
    "ga": "promo_open",
    "action": {
      "kind": "event_action",
      "actionId": "event_action/promotions/<promo-term>",
      "fallbackHref": "https://product.example/promo/<landing-name>"
    }
  }
}
```

- `label` — переклади кнопки (обидві мови).
- `ga` — **GA-мітка**: значення `cta_id` події `cta_click`; цей самий список передається продуктовому
  аналітику (GA-ANALYTICS-SPEC.md §7) — таблиці збігаються за побудовою.
- `action` — лінк або `event_action` (id з офіційної таблиці `assets/EVENT-ACTIONS.md`;
  `fallbackHref` — реальний Path для standalone).
- Типізація — тонкою обгорткою `config/actions.ts` (типи `LandingAction`/`CtaConfig` + `satisfies`),
  тож помилка структури ловиться на білді, а не в проді.

## 4. Мова: `useCopy()` + locale продукту

```ts
// composables/useCopy.ts (Спостережено)
const lang = computed(() => (embed.value.locale === 'ru' ? 'ru' : 'ua'))
const t = (node: Localized) => node[lang.value]
```

- Джерело locale — **контракт**: в embedded строго `IframeBridge.config.locale`, standalone — query
  `?locale=` з дефолтом мови кампанії. Мапінг: `ru → ru`, все інше (`uk`/`en`/відсутнє) → `ua`.
- **Hydration-правило (Спостережено, критичне):** SSG-розмітка завжди дефолтною мовою; locale/auth/канал
  застосовуються **після mount** (`nuxtApp.hook('app:mounted', …)` у плагіні bridge) — перший клієнтський
  рендер збігається з SSR, потім Vue допатчує тексти. Інакше — hydration mismatch на кожному тексті.
- Похідні масиви від `t()` — лише через `computed` (спред `[...items]` невиконуваного computed без
  `.value` — реальний краш, **Спостережено**).

## 5. Процес роботи з копірайтером

1. Розробник створює структуру `copy.json` з фінальною UA-версією (single source: те, що в компонентах).
2. Копірайтеру передається САМ файл (або гілка/PR) — правити значення, не структуру.
3. Повернений файл проходить: (а) `JSON.parse`-валідність, (б) diff-рев'ю (мають змінитися лише
   значення), (в) прогін лендінга обома мовами (`?locale=ru`) + перевірка переносів довгих рядків
   на 390px (RU-тексти зазвичай довші за UA на 5–15%).
4. Нові ключі додає лише розробник (разом із підключенням у компоненті).

## 6. Чекліст

- [ ] Всі тексти (включно з aria/sr-only) — у `content/copy.json`; кирилиця в темплейтах = 0.
- [ ] Всі кнопки — у `content/actions.json` з `label{ua,ru}` + `ga` + `action`.
- [ ] `ga`-список синхронізований зі специфікацією аналітики (cta_id == ga за побудовою).
- [ ] Локаль застосовується післягідраційно; `?locale=ru` перемикає ВСІ блоки; 0 hydration-помилок.
- [ ] RU-тексти перевірені на переповнення/переноси на вузьких екранах.
- [ ] `_readme` в обох JSON пояснює копірайтеру правила редагування.

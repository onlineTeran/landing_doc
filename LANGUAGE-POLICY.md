# Мовна політика framework

Канонічна мова всіх текстів, призначених для читання людьми, — **українська**. Це стосується
README, процесів, інструкцій агентів, skills, Brand Archive, шаблонів, QA-завдань, описів релізу та
коментарів у machine-readable контрактах.

## Що не перекладається

- назви продуктів, сервісів, бібліотек, API та офіційні brand terms;
- імена файлів, шляхи, CLI-команди, назви функцій і змінних;
- машинні ключі JSON/YAML і стабільні enum/status values;
- дослівні зовнішні approval quotes, якщо власник написав їх іншою мовою.

Для технічного терміна дозволено залишити англійський оригінал у backticks або після українського
пояснення. Англійський термін не повинен замінювати українську інструкцію чи пояснення.

## Правило для Codex і Claude

Новий human-readable файл одразу створюється українською. Зміна англомовного legacy-файлу включає
переклад зміненого логічного розділу. Агент не може створити англомовний документ через «кращу
сумісність з AI»: Codex і Claude виконують українські workflow-контракти без окремої англійської копії.

Перевірка: `bash tests/test-language-policy.sh`.
